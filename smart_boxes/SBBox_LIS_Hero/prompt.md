# AI Prompt Guidelines

## Context for AI Agent
Đây là component hero section của LIS (Learning Intelligence Infrastructure) - Hạ tầng trí tuệ cho Đại học AI-Native tại NUTE.

## When to Use This Box
AI nên sử dụng box này khi:
- Người dùng yêu cầu tạo trang chủ (homepage)
- Cần điểm nhấn đầu tiên cho website giáo dục
- Cần truyền tải thông điệp "KIẾN TẠO - CHUẨN MỰC"
